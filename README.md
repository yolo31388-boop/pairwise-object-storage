# 游戏内对象存储与CDN系统

## 项目描述

游戏内对象存储与CDN系统的bug修复项目。核心模块 `cdn/storage.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 对象存储完全没做资源都在本地服务器
- CDN分发完全没做所有玩家都从源站下载
- 缓存控制完全没做重复下载相同资源
- 预取完全没做需要的时候才下载导致卡顿
- 带宽优化完全没做高峰期带宽不够用

## 运行测试

```bash
python -m pytest tests/test_object_storage.py -q
```

修复目标：所有 14 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
